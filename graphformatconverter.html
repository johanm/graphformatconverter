Graph format converter

by Johan Myrberger

GraphML, GEXF, GML, Graphviz DOT, JSON (node-link and Cytoscape.js), edge lists and node/edge CSV (Gephi or Kumu columns). Everything runs in your browser; no file leaves your machine.

Input

Drop files here or click to choose
One graph file (GraphML, GEXF, GML, DOT, JSON, edge list), or a nodes CSV and an edges CSV together
Nothing loaded.

CSV files are recognised automatically: a file with Source/From and Target/To columns is the edge list, any other is the node list. CSV with only edges is fine; nodes are created from the edges. Plain edge lists are read as directed.
Tip: open this page with ?file=https://… to load a file from a URL (repeat file= for a nodes + edges CSV pair). Optional: &format=graphml and &style=gephi preselect the output. The server hosting the file must allow cross-origin requests.

Output format

Transform

Each removed node is replaced by edges between its neighbours: every incoming neighbour is linked to every outgoing neighbour, and undirected neighbours are linked pairwise. New edges get a "relation" attribute holding the removed type (Kumu output writes it into the connection Type column). Nodes without attributes cannot be selected.

Graph preview

ForceAtlas2-style layout, run live. Scroll to zoom, drag the background to pan, drag a node to move it. Layout cost grows quickly above about 1,500 nodes.
