Graph format converter

by Johan Myrberger

GraphML, GEXF, GML, Pajek, Graphviz DOT, JSON (node-link and Cytoscape.js), edge lists and node/edge CSV (Gephi or Kumu columns). Everything runs in your browser; no file leaves your machine.

Input

Drop files here or click to choose
One graph file (GraphML, GEXF, GML, Pajek, DOT, JSON, edge list), or a nodes CSV and an edges CSV together
Nothing loaded.

CSV files are recognised automatically: a file with Source/From and Target/To columns is the edge list, any other is the node list. CSV with only edges is fine; nodes are created from the edges. Plain edge lists are read as directed.
Tip: open this page with ?file=https://… to load a file from a URL (repeat file= for a nodes + edges CSV pair). Optional: &format=graphml and &style=gephi preselect the output. The server hosting the file must allow cross-origin requests.

Output format

Transform

Connect all neighbours links every pair of neighbours of a replaced node, whatever the edge directions (for example, users who liked the same post become linked). Follow edge direction only links an incoming neighbour to an outgoing one, so a node that has only incoming or only outgoing edges produces no new edges. New edges get a "relation" attribute holding the removed type (Kumu output writes it into the connection Type column). Nodes without attributes cannot be selected.

Removed nodes

    Click a node in the graph preview and choose Remove. This deletes the node and its edges (it does not connect its neighbours; use the type transform above for that). Manual removals are applied first, then the type transform. Restore a node here to bring it back with its edges.

    Graph preview

    ForceAtlas2-style layout, run live. Scroll to zoom, drag the background to pan, drag a node to move it, click a node to remove it. Layout cost grows quickly above about 1,500 nodes.
